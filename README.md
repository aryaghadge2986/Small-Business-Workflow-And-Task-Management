# BizFlow - Small Business Workflow and Task Management

## Project Description

BizFlow is a web-based workflow and task management system designed for small businesses.

It helps business owners manage daily tasks, track task progress, and organize their workflow efficiently.

## Features

- Dashboard
- Create and manage tasks
- Task status tracking
- Pending, In Progress and Completed tasks
- Workflow health overview
- Smart assistant recommendations
- Settings page
- Simple and user-friendly interface
- Responsive web design

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

- `index.html` - Dashboard
- `create-tasks.html` - Create Task page
- `tasks.html` - Task management page
- `settings.html` - Settings page
- `style.css` - Website styling
- `script.js` - JavaScript functionality
